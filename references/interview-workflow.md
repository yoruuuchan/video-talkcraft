# 线上采访模式

这个模式处理已经完成基础转写的线上采访。用户负责准备素材，agent 从“编辑”开始工作。

## 输入

默认输入：
- 原始采访 MP4
- 对应 MP3
- SRT
- 采访大纲
- 用户已有的截图、图片、录屏、补充 MP4（如有）

采访模式不负责抽音频、ASR 或生成 SRT。缺少上述核心输入时先报告缺什么，不自行换一套转写流程。

## 总原则

采访大纲决定成片结构，SRT 帮助定位内容，原始 MP4 是画面与声音真值。
先把“说什么”剪对，再决定“看什么”。不要为了展示动效卡而改变采访内容。
线上采访的人像通常小且压缩严重，可以长期缩成角标；共享屏幕质量不足时直接换成更清楚的视觉材料。

## 1. 按大纲粗剪

先把 SRT 内容映射到采访大纲的各个问题/章节。每一章内部再做删留与排序：
- 保留真正回答问题、提供新事实、例子、观点或必要上下文的内容。
- 删除明显的重复、跑题、寒暄、过程话、无信息量的附和与无效问答。
- 同一个问题有多次回答时，优先保留信息完整、表达自然的一版。
- 可以调整回答顺序，让一章内部更顺，但不得拼出原话没有表达过的新结论。
- 不追求“剪得越短越好”；人物自然语气、必要停顿和有价值的个性表达可以保留。
- 采访者的提问在理解上下文时要读，成片是否保留按内容需要决定。

粗剪结束后必须能回答：每一段为什么留下、它属于大纲哪一项、前后是否自然。

建议产物：
- `interview-edit.md`：人类可读的章节顺序、保留内容、源时间段和简短理由。
- `interview-cut.json`：机器可读的保留片段列表，至少包含 `sourceStart`、`sourceEnd`、`section`、`text`。
- 粗剪 MP4：按同一份保留片段裁原始采访，后续视觉包装都基于这个版本。

## 2. 给粗剪内容安排画面

粗剪确定后，再逐段判断观众最应该看什么。优先使用已有真实素材，再决定是否需要重做。

每段从下面几种状态中选：
- `host-chip`：人物小窗 + 主画面内容。线上采访的常用状态。
- `host-focus`：短暂把人物放大，让观众重新看到说话的人或承接较个人化的表达。
- `screen-original`：原共享屏幕清楚、流畅、内容可读，直接使用。
- `screen-rebuild`：共享屏幕讲的是网页、产品、流程或代码，但原画面糊、卡、字不可读；重新截图、录制或在 Remotion 中重做展示。
- `supplement`：用用户已有或新补的 MP4、图片、截图、B-roll 解释内容。
- `motion`：内容本身更适合图表、关键词、流程、关系图等程序动效。

优先级通常是：真实且清楚的原素材 > 更清楚的真实截图/录屏 > 补充视频或图片 > 程序动效。
不要为了“画面一直变”强行替换本来已经足够清楚的内容。

把结果写成 `visual-plan.md`。每个需要处理的区间至少写：
- 成片时间范围
- 这段在讲什么
- 采用哪种画面状态
- 使用哪个素材路径；没有素材就明确写“待补”
- 如果需要新做视频/动效，写清它要解释什么

## 3. 什么时候进入 SHOTBOOK

只有需要 `screen-rebuild` 或 `motion` 的段落必须进入完整 SHOTBOOK。
纯人物、原共享屏幕和直接使用现成补充素材的区间，可以只写简单的画面安排，不要求为了流程完整性硬做层矩阵。

这样可以把 TalkCraft 的动效系统集中用在真正需要解释的地方，而不把整条采访做成连续 explainer。

## 4. 采访版文字密度

采访模式允许一屏承载比默认示例更多的文字。判断标准是“这一屏是否能完整表达一个小主题”，不追求一句话占满一屏。
可以同时出现：
- 一句核心原话 + 1～3 个短要点
- 一个问题标题 + 一段简短结论
- 一个关键词标题 + 两三行解释
- 数据/步骤 + 必要的文字说明

不要把完整 SRT 复制成大段正文，也不要为了“高级感”把本来有关联的信息拆成很多只有一两个词的空镜。
字多时优先建立清楚的标题、正文、注释层级，保证正常观看距离可读。

## 5. 对口播默认规则的采访覆盖

采访模式下：
- “人物有素材时一律角标常驻”改为默认角标，可在内容需要时切回人物。
- B-roll / 图片占比不设硬指标；有解释价值才加。
- 单视频必须套 ThemeFrame 改为可选，版式应服从采访整体视觉系统。
- 不要求每句话都有新动效或新元素。
- 不要求每个区间都进入完整 SHOTBOOK。
- 原始共享屏幕不可读时，不因为“是真实素材”而硬保留。
- 一屏可以有更多文字，只要层级清楚、可读且服务内容。

其余时间同步、素材本地化、Remotion 实现、工作台、渲染和 QA 规则继续沿用主 Skill。

## 6. 完成标准

采访版完成前至少确认：
- 成片结构能对应采访大纲。
- 粗剪没有丢掉关键事实，也没有把不同回答拼成原话不存在的新意思。
- 所有模糊、卡顿或不可读的共享屏幕区间都已经处理。
- 待补素材有明确清单和用途。
- 动效只用在真正需要解释的地方。
- 文字密度比默认示例更灵活，但没有退化成整屏转录稿。
